# Photos needed for bfx_bulgaria portraits

Wikimedia's image server refuses downloads from the build sandbox's cloud IP
("robot policy", HTTP 429), so these have to be downloaded from a normal browser.

**How:** open each link → click **"Original file"** (or "Download") → save it with the
*save as* name below → upload all of them to `hoi4-bulgaria/source_images/` on branch
`claude/beautiful-pasteur-3di5zu` (GitHub web: go to that folder on the branch →
**Add file → Upload files** → commit directly to the branch).

when the files are processed; anything not public domain or CC BY / CC BY-SA is dropped.
